# Video Saver

واجهة ويب عربية خفيفة تعمل على الموبايل ويمكن تثبيتها كتطبيق PWA.

## التشغيل
فعّل GitHub Pages من Settings → Pages → Deploy from a branch → main → /(root).

## الاستخدام
1. الصق رابط فيديو تملك حق تنزيله.
2. اضغط «نسخ الرابط وفتح SaveFrom».
3. الصق الرابط في صفحة SaveFrom واختر صيغة/جودة متاحة.

## ملاحظات
- الواجهة تسهّل نسخ الرابط وفتح خدمة خارجية؛ لا تستخرج ملفات الفيديو بنفسها.
- نزّل فقط المحتوى الذي تملكه أو لديك إذن بحفظه، واتبع شروط المنصة وحقوق النشر.
- لا تتجاوز DRM أو تسجيل الدخول أو المحتوى الخاص أو قيود الوصول.
- الروابط لا يتم تخزينها داخل التطبيق.
