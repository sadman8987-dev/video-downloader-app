# Video Saver + Telegram Bot

المستودع يحتوي على:
- واجهة ويب عربية قابلة للتثبيت كتطبيق PWA.
- بوت Telegram يستقبل روابط HTTPS المباشرة لملفات الفيديو العامة ويرسل الملفات إلى المستخدم.

## تشغيل البوت على Railway
1. أنشئ بوتاً من حساب Telegram الرسمي عبر @BotFather باستخدام الأمر /newbot.
2. احتفظ بالتوكن بشكل سري، ولا تضعه داخل ملفات GitHub أو ترسله في المحادثات.
3. افتح مشروعاً جديداً على Railway واربطه بهذا المستودع.
4. من Variables أضف متغيراً باسم BOT_TOKEN وضع قيمة التوكن.
5. شغّل الخدمة كـ Worker. ملف Procfile وملف railway.toml يحددان أمر التشغيل.
6. افتح البوت في Telegram وأرسل /start.

## ما يدعمه البوت
- روابط HTTPS مباشرة لملفات MP4 وWebM وMOV وM4V العامة.
- حد أقصى 45MB لكل ملف.
- لا يتبع التحويلات تلقائياً، ولا يحاول استخراج الفيديو من صفحات المنصات.

## حدود مهمة
- رابط صفحة فيديو من منصة مثل YouTube أو Facebook أو TikTok ليس رابط ملف مباشر؛ البوت لن يستخرج الملف من الصفحة.
- استخدم فقط ملفات تملكها أو لديك إذن بتنزيلها، واتبع شروط المنصات وحقوق النشر.
- لا يدعم تجاوز DRM أو تسجيل الدخول أو المحتوى الخاص أو قيود الوصول.
- لا تنشر BOT_TOKEN مطلقاً. إذا انكشف، ألغِه وأنشئ توكناً جديداً عبر BotFather.
